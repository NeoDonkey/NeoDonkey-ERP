# NeoDonkey LLM Wiki (Google Open Knowledge Format)

Welcome to the central knowledge base and memory of NeoDonkey-ERP. This wiki is written and maintained according to the Open Knowledge Format (OKF) v0.2 specification.

It is designed to serve as a persistent "digital brain" enabling continuous, fully autonomous handovers from one scheduled Google Jules session to the next.

## Directory Listing

### System State & Handover
* [Update Log](log.md) - Chronological history of all automated and manual development runs.
* [Session Handover](concepts/handover.md) - The active state, what was done in the last session, and the next priorities for this session.

### Core Context & Backlog
* [Project Roadmap](concepts/roadmap.md) - Long-term project backlog and MVP development milestones.
* [System Architecture](concepts/architecture.md) - Principles of the serverless/cloudless, beermat tech stack and two-layer CRDT/Git architecture.
